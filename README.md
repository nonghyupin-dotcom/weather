# 현장 일정 날씨판

오늘 현장 일정과 지역별 날씨를 한 화면에서 보고, 날씨 때문에 주의 · 중지를 검토할 일정을 표시합니다. (교육용 가상 데이터)

## Supabase 연결과 실행
1. Supabase 프로젝트의 SQL Editor에서 `setup.sql`을 직접 실행합니다. 테이블·지역/구분 제약·RLS 정책과 가상 일정 6건을 만듭니다.
2. `config.js`의 두 줄에 프로젝트 URL과 공개용 publishable 키(또는 기존 anon 키)를 입력합니다. secret/service_role 키는 사용하지 않습니다.
3. 변경 사항을 배포한 뒤 Vercel 배포 주소로 접속합니다.
4. 한 브라우저에서 일정을 추가하고 다른 브라우저에서 새로고침하면 같은 일정이 보입니다. 실시간 자동 갱신은 하지 않습니다.

교육용으로 로그인 없이 전체 일정 조회·추가를 허용하며, 수정·삭제는 허용하지 않습니다. 실제 개인정보는 입력하지 않습니다.
기존 JSON·브라우저 저장 일정은 DB에 자동 이전하지 않습니다. `data/tasks.json`은 이전 실습 참고 자료입니다.
설정 전이나 DB 연결 실패 시 화면에 안내를 표시합니다. 현재 표는 ‘오늘판단md로저장’ 버튼으로 내려받을 수 있습니다.
